FOLDER PDF REGULASI — SI-PASTI
==============================

Taruh berkas PDF regulasi di folder ini. Tombol "Buka PDF Regulasi" pada tab
"Unduh" di panel Detail Regulasi akan otomatis membukanya bila berkas dengan
NAMA PERSIS di bawah ini tersedia. Jika berkas belum ada, tombol menampilkan
pesan "belum tersedia".

Nama berkas WAJIB sama persis (huruf kecil semua, tanpa spasi):

  uu-20-2023.pdf           -> UU 20/2023 tentang Aparatur Sipil Negara
  pp-12-2019.pdf           -> PP 12/2019 (Pengelolaan Keuangan Daerah)
  permendagri-77-2020.pdf  -> Permendagri 77/2020
  pergub-ntt-68-2023.pdf   -> Pergub NTT 68/2023
  sop-61-2024.pdf          -> SOP 61/2024 (Pedoman operasional SKPP)

Contoh: letakkan file di public/regulasi/uu-20-2023.pdf
Berkas akan diakses lewat URL /regulasi/uu-20-2023.pdf

Catatan: cukup taruh filenya, tidak perlu mengubah kode. Kalau ingin menambah
regulasi baru, beri tahu agar entri + nama berkasnya ditambahkan.
