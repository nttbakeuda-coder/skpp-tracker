FOLDER PDF PANDUAN — SI-PASTI
=============================

Taruh berkas PDF panduan di folder ini. Tombol "Unduh panduan (PDF)" pada kartu
Panduan (di Beranda maupun halaman Panduan setelah login) akan otomatis
membukanya bila berkas dengan NAMA PERSIS di bawah ini tersedia. Jika berkas
belum ada, tombol menampilkan pesan "belum tersedia".

Nama berkas WAJIB sama persis (huruf kecil semua, tanpa spasi):

  panduan-bendahara-opd.pdf  -> Panduan untuk Bendahara OPD
  panduan-pegawai-ybs.pdf    -> Panduan untuk Pegawai yang Bersangkutan (YBS)

Contoh: letakkan file di public/panduan/panduan-bendahara-opd.pdf
Berkas akan diakses lewat URL /panduan/panduan-bendahara-opd.pdf

Catatan: cukup taruh filenya, tidak perlu mengubah kode.
